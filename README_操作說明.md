# 美樂家 V1.5｜五款必買＋一鍵 GitHub 發布

## 功能

- 官方 2026 年 10 月的 303 筆價目表資料（商品與配件）；每月 5 日 09:37（台北時間）自動核對價目表，無需付費 AI API。
- 目標點數可手動輸入 1–500 點，或快速點選 **35、36、37、38、39、40 點**。
- 可設定 **五個固定必買**，每個都可各選 **1 或 2 件**；各欄獨立提供類別下拉選擇和關鍵字／商品編號搜尋。上方的數量上限只約束系統自動搭配的商品。
- 按最終花費（含運）由低到高列出最多 **五種不同搭配方案**。若數量及可售商品限制使得不足五種，會如實顯示可行數量，不會虛構。
- 商品名稱旁以**分類小圖示**輔助辨識，並非商品實拍照；官方價目表未提供每款商品對應的圖片連結，不用不可靠的網路隨機圖片冒充產品圖。
- 產品可編輯、CSV 匯入匯出、檢查已發布的最新版資料；調整只儲存在目前裝置的瀏覽器。

## 首次建站（Mac 上操作）

1. 解壓 ZIP 到 Mac。
2. 雙擊 `一鍵建立或更新網站.command`，依畫面登入 GitHub（首次需要授權）並輸入 `YES` 確認公開網站與原始碼。若系統阻擋執行，請在終端機用 `bash` 加空格，再把 `.command` 檔案拖入終端機執行。
3. 若未安裝 GitHub CLI，腳本會詢問是否透過已安裝的 Homebrew 安裝。若沒有 Homebrew，請到 https://cli.github.com/ 安裝 `gh` 再執行。
4. 腳本會建立或安全更新 **專用**公開儲存庫 `melaleuca-point-calculator`，啟用 GitHub Pages、觸發 GitHub Actions、等待公開網址可開啟。
5. **驗證上線後**，腳本會在專案資料夾儲存 `網站網址.txt`，自動複製 HTTPS 網址到 Mac 剪貼簿並開啟瀏覽器。以後可雙擊 `一鍵複製已發布網站網址.command` 再複製。
6. 如 Pages 尚未啟用，手動到 GitHub 儲存庫 `Settings → Pages → Source → GitHub Actions`，再到 `Actions` 執行 `monthly-update.yml`。初次公開 Pages 的執行時間受 GitHub 平台影響。

網址格式：`https://你的GitHub帳號.github.io/melaleuca-point-calculator/`（僅格式示例，不是已上線的真實網址）。

注意：**沒有 GitHub 帳號授權時，不能在 ChatGPT 對話中替你直接建立遠端儲存庫**。本套件只是經你確認後，在你 Mac 執行的發布程式，不會在下載時自動對外公開資料，也不會修改旅遊 APP 專案。

## 更新既有 V1.3 網站

在 Mac 把新版 ZIP 解壓後，再次雙擊 `一鍵建立或更新網站.command` 即可；若既有專案不是本計算機，安全檢查會停止，不會覆蓋其他 GitHub 專案。若舊版商品資料已更新到新月份，程序會保留更新後資料。

## 圖片與資料安全

PDF 文件有商品價目表、沒有每款商品對應實拍照。未來可在確認官方商品圖的來源、授權、識別關係和穩定網址後，再為每款 SKU 加入正確縮圖（建議先做精選常用品，點開詳情才載入大圖，以免手機很慢）。目前的 emoji 是**分類輔助圖示**，不是商品圖片。

實際售價、庫存、點數、運費規則請以美樂家官網結帳頁為準。本產品為個人計算工具，非美樂家官方網站。


## V1.5 新增規則

- 目標點數設定 **1～45 點（含 45）** 時，依商品實際用途／系列，同類型商品（不同口味／香味）整單最多 **2 件**，包含固定必買和自動搭配。
- 即使計算結果超過 45 點，限制仍以「輸入目標點數」判斷，不會失效。
- 目標 46 點以上不啟用跨商品編號的同類型兩件限制；但各商品編號仍遵守自選最多 1／2 件。
- 宅配（預設左側）：未滿 50 點加 NT$125，50 點以上運費 0。店面購買（右側）：運費 0，僅生活館商品也可以納入。仍須核對生活館價格、庫存和營業資訊。
- 同類型群組由商品名稱規則自動推斷。若品牌命名特殊，可在「修改商品」設定群組，或 CSV 欄位 `同類型群組` 校正。這是價格比較工具，不保證官方優惠／套組限制。
- 含複數件的日常套組，計算同類型件數時會根據品名中的「任2／任3／2瓶組」等標註計算；混合不同類型的複雜套組需要人工核對實際內容。
